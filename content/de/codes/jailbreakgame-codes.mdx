## Fehlerbehebung bei häufigen Einlöseproblemen

Probleme an einem Geldautomaten können frustrierend sein – besonders dann, wenn die Alarmanlage der Bank schrillt oder Streifenwagen in der Nähe patrouillieren. Die meisten Fehler sind auf kleine Tippfehler oder kurze Synchronisationsverzögerungen des Servers zurückzuführen.

| Fehlersymptom | Wahrscheinliche Ursache | Lösungsansatz |
| :--- | :--- | :--- |
| **Terminal schließt sich sofort** | Code abgelaufen oder bereits eingelöst | Prüfe die Liste abgelaufener Codes; jeder Code funktioniert nur einmal pro Account. |
| **Meldung „Ungültiger Code“** | Tippfehler oder falsche Groß-/Kleinschreibung | Kopiere den Code direkt und füge ihn ein, um Schreibfehler zu vermeiden. |
| **Leerzeichen am Anfang/Ende** | Formatierungsfehler beim Kopieren | Achte darauf, keine versehentlichen Leerzeichen vor oder nach dem Code mitzukopieren. |
| **Keine Belohnung sichtbar** | Server-Lag oder verzögerte Inventar-Synchronisation | Rüste Gegenstände in der Garage neu aus oder trete einem neuen Server bei. |

Wenn du deine Schreibweise überprüft hast und das Terminal die Eingabe weiterhin ablehnt, ist der Code mit großer Wahrscheinlichkeit abgelaufen oder wurde auf deinem Profil bereits eingelöst.
